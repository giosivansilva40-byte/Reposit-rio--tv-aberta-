# Contribuindo para Rio TV Aberta Player

Obrigado por seu interesse em contribuir! Este documento fornece diretrizes e instruções para contribuir com o projeto.

## 🤝 Como Contribuir

### Reportando Bugs

1. Abra uma [issue](https://github.com/giosivansilva40-byte/Reposit-rio--tv-aberta-/issues)
2. Descreva o bug em detalhes:
   - Qual é o comportamento esperado?
   - Qual é o comportamento atual?
   - Passos para reproduzir
   - Screenshots (se aplicável)

### Sugerindo Melhorias

1. Abra uma [discussion](https://github.com/giosivansilva40-byte/Reposit-rio--tv-aberta-/discussions)
2. Descreva sua sugestão:
   - Qual é o problema que resolve?
   - Como você imagina a solução?
   - Exemplos de implementação

### Fazendo Pull Requests

1. Fork o repositório
2. Crie uma branch para sua feature (`git checkout -b feature/amazing-feature`)
3. Commit suas mudanças (`git commit -m 'Add amazing feature'`)
4. Push para a branch (`git push origin feature/amazing-feature`)
5. Abra um Pull Request

## 📋 Checklist antes de contribuir

- [ ] Verifiquei que o código segue o estilo do projeto
- [ ] Testei em múltiplos navegadores
- [ ] Testei em dispositivos móveis
- [ ] Atualizei a documentação (se necessário)
- [ ] Meu código não quebra testes existentes

## 💻 Configuração do Ambiente

```bash
# Clone o repositório
git clone https://github.com/giosivansilva40-byte/Reposit-rio--tv-aberta-.git
cd Reposit-rio--tv-aberta-

# Abra index.html em um servidor local
python -m http.server 8000
```

## 📝 Padrões de Código

- Use nomes descritivos para variáveis e funções
- Adicione comentários para código complexo
- Use `const` por padrão, `let` quando necessário
- Evite `var`
- Use arrow functions quando apropriado

## 🎨 Padrões de Design

- Cores: Preto (#000000), Amarelo (#FFD700)
- Fonte: Segoe UI, Tahoma, Geneva, Verdana
- Responsividade: Mobile-first
- Acessibilidade: WCAG 2.1 AA

## 📱 Compatibilidade

Teste em:
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

## 🐛 Processo de Revisão

1. Um mantenedor revisará seu PR
2. Mudanças podem ser solicitadas
3. Após aprovação, será feito merge
4. Seu nome será creditado

Obrigado por contribuir! 🎉
